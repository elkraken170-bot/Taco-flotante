# Taco Flotante v0.5 — APK desde el celular

Este proyecto incluye un workflow de GitHub Actions para generar el APK de prueba sin computadora.

## Pasos
1. Crea un repositorio nuevo en GitHub desde el celular.
2. Sube el contenido de este proyecto al repositorio.
3. En GitHub abre **Actions** → **Build Taco Flotante APK** → **Run workflow**.
4. Espera a que termine el proceso.
5. En la ejecución terminada, abre **Artifacts** y descarga `TacoFlotante-v0.5-debug`.
6. Extrae el ZIP y abre `app-debug.apk` en tu HONOR X9 para instalarlo.

Si Android muestra un aviso de seguridad, permite temporalmente la instalación desde la aplicación (por ejemplo, el navegador o gestor de archivos) que abrió el APK.
